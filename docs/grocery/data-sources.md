## 1. 쇼핑 가격

### 1-1. 네이버 쇼핑 검색 API — 종료

- **2026-07-31에 종료됐다.** 유예 없음, 기존 키도 호출 불가, NAVER API HUB 포함 대체 API 없음. 공지 원문으로 확인: https://developers.naver.com/notice/article/32530 , https://developers.naver.com/notice/article/32564
- HUB의 Shopping Insight는 클릭 추이 비율만 주고 가격·판매처가 없다.
- 네이버 가격비교 페이지(search.shopping.naver.com)는 robots.txt가 모든 봇에 `Disallow: /`이고, 직접 요청하면 HTTP 418(접속 제한)이 돌아온다.

### 1-2. 상품 페이지 구조화 데이터(JSON-LD)

서버에서 상품 페이지 원본을 받아 schema.org `Product/Offer`의 `price`를 읽는 방식. 2026-10-16 curl로 확인.

- 원칙(제안): robots.txt가 막는 곳과 약관이 자동 수집을 금지하는 곳은 수집하지 않는다. 허용된 곳도 품목 확인 때 한 번씩만 받고 캐시한다.
- **상품 주소 찾기(2026-10-19, 이 작업 환경에서 curl, 검색 1건씩)**:
  - 컬리 `www.kurly.com/search?sword=`: robots 허용(별표 그룹 Allow /). 서버 HTML(76KB)의 `__NEXT_DATA__`에 검색 결과 상품이 없다 → 브라우저에서 따로 불러오는 구조. 서버에서 주소를 찾으려면 컬리 내부 API를 불러야 한다(장보기는 쓰지 않음. 알아보기는 D-036부터 그 API를 쓴다, 11절).
  - 홈플러스 `mfront.homeplus.co.kr/search?keyword=`: robots 허용. 서버 HTML 7.5KB로 상품 없음(브라우저에서 그림).
  - CJ더마켓: 첫 화면이 `/the/pc/main`(Vue 앱, 850KB). 검색 결과는 브라우저에서 그린다(검색 주소를 서버 HTML에서 찾지 못함).
  - 에누리 `price.enuri.com/search?keyword=`: robots 허용(`/api/*` 금지, Crawl-delay 1). 서버 HTML(1.4MB)에 JSON-LD `ItemList` → `Product`(이름, `sku`=에누리 모델번호, `AggregateOffer` lowPrice·highPrice·offerCount, `aggregateRating`). 예: "CJ제일제당 비비고 왕교자 1.05kg" lowPrice 27,090·판매처 284·평점 4.8(8,956). lowPrice는 묶음 수량일 수 있다(다나와와 같은 문제).
  - 결론: 컬리·홈플러스·CJ더마켓은 서버가 스스로 상품 주소를 찾을 수 없다.
- **상품 페이지(주소를 알 때) 다시 확인(2026-10-19, 1건씩)**:
  - 컬리 `www.kurly.com/goods/5082274`: JSON-LD `@graph` 안 `Product`의 `offers.price` 10980(숫자), `additionalProperty`에 "판매단위 1봉", "중량/용량 1050g". 평점 없음, `review`(후기 본문·가린 작성자 이름)가 함께 온다 → 후기 본문은 저장하지 않는다.
  - 홈플러스 `mfront.homeplus.co.kr/item?itemNo=120074651&storeType=HYPER`(front.도 mfront로 넘어감): JSON-LD `Product` 이름 "농심 신라면 120G*5입", `offers.price` "4150"(글자), `aggregateRating` 4.9·121,683. `price`가 "0"인 상품이 있다(1-2 표) → 0이면 버린다.
  - 로우차트 `www.lowchart.com/{쿠팡 productId}-{itemId}`(사이트맵의 상품 주소 모양): robots 허용(`/api/`, `?keyword=` 등 금지). JSON-LD `Product`: `offers.price`(현재가)·`validFrom`, `aggregateRating`, `additionalProperty`에 "관측 최저가", "관측 최고가", "관측 평균가", "최근 가격 변동일", "단위가", "배송". 쿠팡 주소 `/vp/products/{productId}?itemId={itemId}`에서 만들 수 있다(쿠팡에는 요청하지 않는다).
  - CJ더마켓: 사이트가 `/the/` 구조로 바뀌어 옛 상품 주소(`/pc/prod/prodDetail?prdCd=`)가 `/the/product/product-main?prdCd=`로 넘어간다. 새 페이지에는 JSON-LD가 없고 값이 Nuxt 앱 데이터에만 있다(10-16에 본 `price`·`gtin13`이 사라짐) → 읽지 않고 바로가기로 둔다(D-013).
- 참고 판례: 여기어때 크롤링 사건은 형사 무죄(대법원 2021도1533)였지만 민사에서는 부정경쟁방지법 위반으로 10억 원 배상(2018가합508729)이 인정됐다. 대량 수집은 하지 않는다.
- 확인 필요
  - 각 몰 이용약관의 자동 수집 조항(컬리·CJ더마켓·홈플러스·다나와). 다나와 약관은 인코딩이 깨져 읽지 못했다.
  - Supabase Edge Functions(해외 IP일 수 있음)에서 요청해도 막히지 않는지(추측: 막힐 수 있음).

### 1-2-1. 종합 가격비교·가격 추적 사이트 (2026-10-16 curl로 robots와 페이지 1~2건씩 확인)

|---|---|---|---|---|
| 다나와 `/info/` | 허용(`/info/ajax/`·`/api/`·`/bridge/` 금지) | 제24조② "영리목적" 복제 금지(2026-07-13 시행). 자동 수집 조항은 찾지 못함 | JSON-LD AggregateOffer + **HTML 본문에 "쇼핑몰별 최저가" 약 10줄**(`data-base-price`, `data-delivery-price`, 몰 로고 alt=몰 이름) | 11번가, 옥션, G마켓, 롯데ON, 배민상회, 신세계몰, 이마트몰, 현대Hmall, W쇼핑 |

- **2026-10-19 다시 확인(집 PC에서 curl, 요청 3건)**:
  - 다나와 검색 `search.danawa.com/?query=…`(옛 `dsearch.php`는 이 주소로 307): robots 허용, **Crawl-delay 10**(10초에 한 번). 응답 HTML 한 장에 상품 40개가 서버에서 그려져 온다(`li[data-product-seq]` = pcode). 줄마다 상품명(용량 포함, 예: "CJ제일제당 비비고 왕교자 1.05kg"), 수량별 최저가(1개·2개 등), 100g당 가격이 있다. JSON-LD `ItemList`에는 앞 6개만(이름·주소·이미지, 가격 없음). 클래스 이름이 Tailwind라 구조가 바뀌면 깨지기 쉽다.
  - 다나와 상품 페이지 `prod.danawa.com/info/?pcode=`: JSON-LD `Product`에 `AggregateOffer`(lowPrice, offerCount)와 `AggregateRating`(예: 4.8, 후기 9,099). 본문 "쇼핑몰별 최저가"에 약 10줄: 가격·배송비(`data-base-price`, `data-delivery-price`)와 몰 로고 `alt`(롯데ON, G마켓, 옥션, 11번가, SSG.COM, 신세계몰, 이마트몰 등). 바코드(gtin)는 없다.
  - 주의: 상품 페이지는 기본 수량이 묶음(예: "1.05kg (3개)" lowPrice 27,650)일 수 있고, 검색 결과의 1개 가격(10,380)과 다르다. 수량을 맞춰 비교해야 한다.
  - **Supabase Edge Functions에서도 막히지 않는다**(2026-10-19 임시 함수 `danawa-probe`로 한 번씩 호출): 실행 리전 `ap-northeast-2`(서울), 검색 200·후보 40개·0.5초, 상품 페이지 200·AggregateOffer 있음, 차단 문구 없음. 시험 뒤 그 함수는 외부 호출 없이 410만 돌려주게 바꿨다(대시보드에서 지워도 된다).
- 쓰지 않는 곳: 폴센트·11번가(robots 전체 금지, 11번가 Open API 문서는 있으나 현행 여부 미확인), G마켓·옥션(약관 제36조 자동 접속 프로그램 금지, 403), 카카오 쇼핑하우(robots 금지), 위메프(2025-11-10 파산), 티몬(영업 안 함).
- 마트 전단: 이마트 전단은 robots 금지, 홈플러스 종이전단은 가격이 한글 수사("칠천팔백구십원")라 오독 위험, 롯데마트는 브라우저에서 그리는 구조, 킴스클럽은 공식 웹 전단 없음 → 보류.
- 오아시스마켓: robots.txt 없음, JSON-LD 없음(가격은 HTML 클래스에만).
- 다나와와 에누리는 운영사(커넥트웨이브)가 같다. 표본 3건에서 쿠팡·컬리·홈플러스는 판매처로 나오지 않았다.
- 확인 필요: 다나와 MCP의 서버 이용 가능 여부와 조건(커넥트웨이브 문의), 에누리·다나와의 식품 판매처 범위, 로우차트·오아시스 약관, 쿠팡이츠마트·배민B마트(추측: 앱 전용).
- 원칙(제안): 다나와를 1순위로 품목별 하루 한 번만 받아 캐시하고 robots 금지 경로는 받지 않는다. 약관이 금지하는 것은 영리목적 복제이고 이 앱은 비상업이지만, 법적 판단은 아니다.

### 3-1. 공공데이터포털 게이트웨이판 — 사용자가 키를 받은 API (2026-10-19 확인)

- 이름: "한국농수산식품유통공사_일별 도,소매 가격정보 조회", 공공데이터포털 15156057, https://www.data.go.kr/data/15156057/openapi.do. 등록 2025-12-08, 수정 2026-09-21, 이용허락범위 제한 없음, JSON+XML. 사용자가 개발계정으로 활용 신청했고, 키를 Supabase Edge Function Secrets에 넣었다(사용자 말, 비밀 이름은 확인 필요).
