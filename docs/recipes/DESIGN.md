# 레시피 탭 DESIGN

기준은 저장소 맨 위 `DESIGN.md`(가계부)와 `docs/grocery/DESIGN.md`다. 색, 글꼴(SUIT), 반경(태그 4, 칩·버튼 6, 안쪽 칸 8, 묶음 12, 시트 16), 간격(4의 배수, 좌우 20), 그림자 없음, 터치 대상 44px 이상은 그대로 따른다. 여기에는 레시피에서 늘어난 것만 적는다.

## 위치와 CSS

- 코드는 `src/recipes/`, CSS는 `src/recipes/recipes.css`. 모든 선택자가 `.recipes`로 시작하고, 클래스 이름은 `rcp-`로 시작한다. 가계부 `styles.css`는 `rc-`(고정 지출)를 이미 쓰고 있어 `rc-`를 피했다. 겹치는 이름이 없어서 `styles.css`에 `:where(:not(.recipes *))` 막이를 더하지 않았다. `tests/recipes/tokens.test.ts`가 선택자 범위와 이름 겹침을 검사한다.
- 토큰은 가계부 것을 쓰고 `.recipes` 안에서 `--ink-3`(귀리 면 위 4.5:1, 라이트 `#726D65`·다크 `#A09A90`), `--clay-soft`, 다크 입력칸 테두리만 장보기처럼 따로 둔다.

## 탭

- 아래 탭 일곱째, `장보기` 바로 다음. 아이콘은 Phosphor `cooking-pot`(켜면 `-fill`), 글자 "레시피"(3자). 칸은 `repeat(7, minmax(0, 1fr))`. 넓은 화면은 왼쪽 메뉴의 같은 자리.
- `?tab=recipes`로 열 수 있다. `?add=<주소>`가 함께 오면 맨 위에 "이 영상을 담을까요?"와 정규화한 주소, "담기"·"닫기"를 보인다. 누르기 전에는 아무것도 넣지 않는다. 처리한 뒤 주소 줄에서 `tab`·`add`를 지운다.

## 화면 규칙

- 맨 위에 담기 칸과 "담기"(주 버튼). 그 아래 "PC·맥에서 담기"(글자 단추)를 펴면 북마크릿 글(`<code>`)과 "복사". 복사가 막히면 글을 골라 주고 직접 복사하라고 적는다.
- 처리 줄은 귀리 면 한 묶음. 처리 중 줄은 처리기가 쓴 `stage` 글을 그대로 보인다. 우리가 말을 바꿔 쓰지 않는다. 진행 글은 정해진 일곱 개뿐이고 "AI"·"분석"이라는 말은 화면 어디에도 쓰지 않는다.
- 2분 넘게 기다린 줄에서 처리기가 5분 넘게 보이지 않으면 "맥이 켜지면 처리돼요"와 "맥 처리기 마지막 확인: N분 전"(본 적 없으면 "확인 기록 없음"). 색만으로 알리지 않는다.
- 실패 줄은 까닭 그대로와 "다시 하기". 이미 같은 일이 있으면 "이미 담겨 있어요".
- 거르기는 요리 종류·주재료·조리법·난이도·상황 선택 칸 다섯(위 분류 낱말 그대로)과 칩 넷(즐겨찾기, 지금 만들 수 있음, 1~2개만 사면 됨, 확인 필요 N). 칩은 눌리면 먹색 칠 + 굵게. 높이 44px.
- "지금 만들 수 있음"·"1~2개만 사면 됨"은 `recipe.cookable`(사전에 있는 필수 재료만 센다)에서 온다. 줄에는 "가진 재료 3/4"만 적고, 만들 수 있다고 장담하는 말을 쓰지 않는다. 사전에 없는 재료를 세지 않았다는 안내는 상세 화면에 둔다.
- 목록 줄은 구분선만, 카드 틀 없음. 제목 16px 700, 둘째 줄은 쉼표로 이은 13px 보조 글자(요리 종류, 주재료·세부 재료, 조리법, 난이도, 가진 재료). 쉼표로 잇고 ` · `를 쓰지 않는다.
- 빈 상태는 그림 없이 한 문장: "아직 담은 레시피가 없어요. 위 칸에 유튜브 주소를 붙여 넣어 담아 보세요."
- 출처 글은 `originLabel`이 만든다: "설명란", "말 4:02", "화면 0:14", "작성자 자막 1:10", "직접 고침", "덧붙임". 영상 지점은 `videoAt`이 만든 유튜브 주소로 연다.

## 상세 화면

- 맨 위 "목록으로", 레시피 이름(17px 700), 한 줄 설명, 묶음 면(귀리 면, 반경 12) 여러 장으로 나눈다: 출처·분류·난이도·계량 도구 / 인분 / 재료 / 순서 / 원리 / 다른 곳 / 고친 곳. 맨 아래 "고치기"·"지우기"(보조 단추, 지우기는 `--danger` 글자).
- 출처 영상은 제목·채널·길이를 글 한 줄로, 제목이 유튜브 링크다. 썸네일은 쓰지 않는다. 링크는 모두 새 탭(`rel="noopener noreferrer"`).
- 난이도 한 줄은 근거 그대로: "재료 14 · 단계 12 → 보통"(손이 많이 가면 " · 손 많이 감"). 계량 도구가 '확인 못 함'이면 "계량 도구 확인 못 함"을 적고 ml를 붙이지 않는다. '계량스푼'이면 큰술·작은술 옆에 "(30ml)", '밥숟가락'이면 ml 없이 "· 밥숟가락 기준".
- 인분: 기준 줄("기준 2인분(덧붙임, 영상에 인분 없음)" 또는 "기준 N인분") 아래 1~8 칸. 390px에서는 4칸씩 두 줄(칸마다 44px 이상), 720px부터 한 줄. 기준이 아니면 분량 줄에 "원래 2큰술 → 4큰술". 인분을 알 수 없으면 칸을 없애고 적힌 그대로 보인다.
- 덧붙인 값(분량·단계 팁·용어 풀이)은 `--clay` 글자와 "덧붙임" 표시(`--clay-soft` 바탕 작은 글)를 달아 출처 값과 늘 구별한다. 출처 값에는 출처 글(`originLabel`)을 작게 단다. 영상 시각이 있는 출처("말 4:02")와 단계의 "영상 4:05"는 그 지점을 여는 링크다.
- 용어 풀이: 글 한 덩이(재료 이름, 재료 메모, 단계 글, 신호)에서 처음 나온 자리만 점선 밑줄 단추로 그린다. 누르면 그 자리 아래에 풀이 창이 열리고 풀이, 출처("덧붙임" 또는 "영상 1:23" 링크), "닫기"가 있다. Esc로 닫으면 밑줄 단추로 포커스가 돌아온다.
- 고친 곳: 한 줄에 대상과 "전 → 후", 오른쪽에 "되돌리기". 같은 칸의 값·출처·시각 고침은 한 줄로 묶는다. 영상 자막을 바로잡은 기록처럼 되돌릴 수 없는 줄에는 단추를 두지 않는다.
- 가진 재료: "가진 재료 N/M"(사전에 있는 필수 재료만), 사전에 없는 재료가 있으면 "사전에 없는 재료 N개는 세지 않았어요". 재료 줄마다 "있음" 켜고 끄기 칩(사전 키가 있는 재료만, "늘 있음"은 끌 수 없음). "모자란 재료 장보기에 담기"는 모자란 것이 없으면 꺼진다.
- 고치기 시트: 아래에서 올라오는 시트(넓은 화면은 가운데 창), 이름·요리 종류·주재료/세부 재료/조리법(1~3)·상황(0~4)·난이도·별점·즐겨찾기·메모, 재료와 단계 글. 저장은 시트 아래에 붙고 고칠 수 없는 상태면 까닭을 한 줄로 알린다. 지우기는 가운데 창에서 한 번 더 묻는다(`alertdialog`).
- 영상에서 온 글은 모두 글자로만 그린다. 화면에 "AI"·"분석"이라는 말을 쓰지 않는다.

## 확인 화면

- 상세 맨 위 "확인하기 N"(확인할 항목이 있을 때만)과 레시피북에서 "확인 필요 N" 거르기를 켠 뒤 "확인 시작"으로 연다. 상세 자리를 그대로 채운다(시트 아님).
- 항목은 한 번에 하나, "n / N". 제목은 항목 이름("설탕 분량", "양념장 섞기 타이머", "인분"), 아래에 까닭, "지금 값", 후보 목록. 후보 한 줄은 적힌 값 + 출처 글(`originLabel`), 영상 시각이 있으면 "▶ 말 0:10"이 그 장면을 여는 링크(새 탭). 단위는 적힌 그대로, 큰술·작은술을 ml로 바꾸지 않는다. 시간은 분:초.
- 후보마다 "이 값" → `resolveReview`(출처·시각은 store가 user로 둔다). "직접 고치기"는 입력칸과 "이 값으로 저장"·"취소". 분량·인분은 0보다 큰 숫자, 타이머는 초나 분:초(0보다 크게), 글은 DB 한도 안(재료 이름 60자 등). 틀리면 저장소를 부르지 않고 입력칸 아래에 `role="alert"`로 알린다.
- 엇갈림·계량 도구·원리 같은 항목은 두 말을 나란히 보이고 "확인함"만 둔다(값은 바꾸지 않는다). "나중에"는 처리하지 않고 넘긴다. 끝에는 "확인을 마침"(남은 항목이 있으면 몇 개인지 적는다).
- 열릴 때와 항목이 바뀔 때 제목(h2)으로 포커스가 간다. 단추는 모두 44px 이상.

## 요리 화면

- 상세의 "요리 시작"으로 연다. 탭 위를 가득 채우는 `role="dialog"`(고정, `z-index 40`), 상세에서 고른 인분이 그대로 간다. 위에 "n / N"과 "나가기", 아래에 "이전"·"다음"(마지막 단계는 "요리 끝") 56px 단추 둘.
- 단계 제목 26px 700, 본문 22px(줄 높이 1.6), 불 세기·넘어가는 신호는 18px 보조 글자. 글은 모두 글자로만 그린다. 단계가 바뀌면 제목으로 포커스가 간다.
- 그 단계에 쓰는 재료(`uses`)를 체크 상자와 함께 보인다. 분량은 고른 인분으로 계산해 "원래 500g → 1000g"로 적고, 기준 인분이면 원래 값을 따로 적지 않는다. 체크는 이 화면 안에서만 남고 저장하지 않는다. "재료 모두 보기"를 펴면 전체 재료.
- 타이머는 단계에 `timer_seconds`(출처 시간)가 있을 때만 그린다. 큰 숫자 48px, "타이머 시작·멈춤·처음으로". 상태 글은 `role="status"`로 알리고(숫자는 읽지 않는다), 끝나면 "시간이 됐어요"와 가능하면 진동. 소리는 내지 않는다. 단계를 옮기면 새로 맞춘다.
- 마지막 단계에 "다 쓴 재료 끄기": 사전 키가 있고 가진 재료가 '있음'인 것만 칩으로 보이고(늘 있음은 끌 수 없어 뺀다), 누르면 `setPantry(키, null)`. 실패하면 칩을 남기고 알린다.
- 켜 두기: 열 때 `navigator.wakeLock.request('screen')`, 화면이 다시 보일 때 다시 요청, 나가면 놓는다. 지원하지 않거나 거절돼도 아무 말 없이 넘어간다.
