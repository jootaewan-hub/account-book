## 열린 문제

- yt-dlp로 실제 받기를 확인하지 못했다. claude.ai 작업 환경은 영상 사이트에 접속할 수 없다. R2에서 PC로 확인한다.
- 유튜브가 자막 받기를 막으면 L1이 멈춘다. 그때의 길: 브라우저로 스크립트 패널 읽기(2026-11-18에 된 방식), 받아쓰기(L2).
- claude.ai에서 휴대폰만으로 자막을 읽는 길이 아직 없다(내장 브라우저는 데스크톱 앱이 켜져 있어야 한다). P-08.
- 인스타 릴스가 로그인 없이 어디까지 되는지 모른다. R6.
- 쿡앱의 전체 사전이 PC에 남아 있는지 모른다. 없으면 필요할 때 늘리는 사전으로 간다.
- 장보기 품목 이름이 재료 사전에 얼마나 맞는지 모른다. R7.
- `review_count`는 등록 때만 계산된다. 앱에서 고치면 앱이 다시 세어야 한다. R1 설계에서 트리거로 바꿀지 정한다.
- `recipe.ingredient_dict`를 앱 사용자가 못 고치므로, 검토 화면에서 "사전에 더하기"를 하려면 함수가 하나 필요하다. R7.
- 기준 답안의 `duration_seconds` 780은 자막 끝 시각으로 어림한 값이다. R2에서 yt-dlp 값으로 바꾼다.
- 이 묶음은 공개 저장소의 main을 보고 썼다. 로컬에 더 새로운 결정(D-056 이후)이나 구조 변화가 있으면 그쪽이 맞다.
