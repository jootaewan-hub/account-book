# 레시피: 무엇을 만드는가

부부 두 사람이 쓰는 레시피북이다. 가계부 앱의 일곱째 탭 '레시피'(D-056)이고 장보기와 이어진다. 2026-11-19 승인된 설계(`docs/superpowers/specs/2026-11-19-recipes-design.md`)를 따른다. 사용자가 정한 것과 그 순서는 `tracking/brainstorm.md`(1~24번)에 있다.

## 요구사항 (사용자 말 요지)

> 앱에 특정 레시피 주소를 올리면 얘가 실시간으로 분석해서 자세한 레시피 등을 옵시디언이나 이메일 혹은 앱에서 보기 편하게 레시피를 구성해서 만들어주는 걸 원한다. (2026-11-18)

- 유튜브 영상과 쇼츠 주소를 올리면 재료와 순서를 자세히 읽어 정리한다. 영상을 다시 보지 않아도 따라 할 수 있어야 한다.
- 분량은 영상 그대로 적고(큰술·작은술은 15ml·5ml로 맞는지 검증), 덧붙인 값은 늘 따로 보인다.
- 분류해서 레시피북으로 쌓고, 구글 드라이브와 옵시디언에 보관한다. 메일은 보내지 않는다.
- 가진 재료로 만들 수 있는 요리를 보고, 모자란 재료는 장보기 목록에 담는다.
- 요리할 때는 주로 휴대폰으로 본다.

## 쓰는 흐름

1. **담기.** 레시피 탭 맨 위 주소 칸에 붙여넣거나(휴대폰), PC·맥 브라우저 북마크로 보낸다. 같은 영상이 이미 있으면 그 레시피를 연다. 대기함에 한 줄이 생기고, 맥이 켜져 있으면 바로 읽기 시작한다. 꺼진 시간에는 "맥이 켜지면 처리돼요"로 기다린다.
2. **확인.** 맥이 비교해서 고칠 수 있는 것은 스스로 고치고 "고친 곳"에 남긴다. 가리지 못한 것만 "확인 필요"로 뜨고, 누르면 유튜브가 그 장면부터 열린다. 확인 필요가 없으면 바로 레시피북에 들어간다.
3. **요리.** 레시피를 열어 1~8인분을 고르고(영상 값과 덧붙임을 구분해 보임), 요리 화면에서 한 단계씩 따라간다. 단계마다 영상의 그 장면으로 갈 수 있다.
4. **뭐 해 먹지.** 가진 재료(지금 있음·늘 있음)를 기준으로 지금 만들 수 있는 요리와 한두 가지만 사면 되는 요리를 본다. 모자란 재료는 한 번에 장보기 목록에 담는다.

## 화면

| 화면 | 내용 |
|---|---|
| 레시피북 | 맨 위 담기 칸, 처리 중·대기·실패(진행 단계 글과 "다시 하기"), "확인 필요 N", "가진 재료", 거르기(요리 종류·주재료·조리법·난이도·상황·즐겨찾기·지금 만들 수 있음·1~2개만 사면 됨), 찾기(이름·재료) |
| 상세 | 출처 영상(제목·채널·길이), 분류와 난이도 근거, 계량 도구, 인분 바꾸기, 재료(묶음별, 원래 표기, 출처 표시와 그 장면으로 가기, 덧붙임은 따로, 있음·없음), 순서, 용어 풀이(밑줄), 원리, 다른 곳, 고친 곳(되돌리기), 우리 집 메모·별점, 고치기 |
| 확인 | 확인 필요를 하나씩: 까닭, 후보 값(출처·시각), ▶ 그 장면, "이 값", "직접 고치기" |
| 요리 화면 | 휴대폰 기준. 큰 글씨, 한 단계씩, 쓰는 재료와 분량, 넘어가는 신호, 출처에 시간이 있을 때만 타이머, 재료 체크, 화면 꺼짐 방지, 끝에 "다 쓴 재료 끄기" |
| 가진 재료 | 늘 있음·지금 있음, 사전에서 찾아 더하기, 끄기, "장보기에서 산 것을 넣을까요?" |

화면 규칙은 `DESIGN.md`(이 폴더)와 가계부 `DESIGN.md`, `docs/grocery/DESIGN.md`를 따른다.

## 지킬 성격

- 숫자는 출처가 있는 것만. 출처가 무엇인지 늘 보인다("설명란", "말 4:02", "화면 0:14"). 덧붙인 값은 다른 색·작은 글자에 "덧붙임"을 달아 영상 값과 구분한다.
- 화면에 "AI", 채팅창, 반짝이, "분석 중" 같은 말을 쓰지 않는다. 진행은 "영상 정보 받는 중", "화면 글자 읽는 중"처럼 하는 일을 그대로 적는다.
- 영상을 본 사람이 쓴 요약이 아니라, 다시 영상을 보지 않아도 요리할 수 있는 작업 지시서.
- 원본 영상을 대신하지 않는다. 출처 링크와 단계별 시각을 앞에 둔다.

## 하지 않을 것 (D-063)

- 공개 서비스, 레시피 공유·검색 사이트. 두 사람만 쓴다.
- 영상·소리·자막 원문 보관. 정리한 결과와 출처만 남긴다.
- 인스타 릴스, 메일 보내기, 블로그·사진·직접 쓰기로 담기, 2차 자료(기사·블로그) 대조.
- 쿡앱의 8만 건 영문 레시피, 풍미 과학, 검색 서버. 쿡앱을 다시 꺼낼 때는 `tracking/brainstorm.md`의 "쿡앱을 다시 꺼낼 때 쓸 것"에서 출발한다.
- Gemini, 아이폰 단축어, GitHub Actions로 읽기.
- 영양 계산. 장보기의 성분 탭이 이미 식약처 자료를 쓰고 있어 필요해지면 그쪽과 잇는다.
